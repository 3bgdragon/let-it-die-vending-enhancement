제목: [모드] 자판기 강화 v1.0 — 킬코인 재료 구매 / 데칼 관리 / 탄약 충전

전에 세이브툴 글에서 재료를 킬코인으로 살 수 있게 해달라는 요청이 있었음.
좋은 기능인 것 같아서 만들어보려고 했는데, 세이브툴 안에 넣기엔 게임 파일이랑 UI까지 건드려야 해서 범위가 너무 커지더라.
그래서 몇 가지 기능 더 넣어서 별개의 자판기 강화 모드로 배포함.

1. 킬코인 재료 상점

재료 106종 중 최대 7종이 랜덤으로 진열됨.
한 상품당 5개 묶음이고 가격은 희귀도별 고정임.
처음 적용하면 다음 날까지 기다리지 않도록 최초 입고도 넣었음.
그 뒤에는 기존 일일 갱신을 따르는 방식이고 재접속한다고 계속 채워지진 않음.
기존 상품이랑 블러드늄 상점은 그대로 둠.

2. 데칼 교체 / 탈착

자판기에서 기존 버섯상점의 데칼 관리 화면을 열 수 있게 연결함.
일반/프리미엄 데칼의 기존 탈착 규칙을 바꾸는 기능은 아님.

3. 탄약 충전

데스백에 있는 탄약형 무기를 골라서 장전탄이랑 예비탄을 채울 수 있음.
비용은 해당 무기 강화 단계 구입가의 20%고 금고 킬코인으로 결제됨.
내구도까지 수리해주는 건 아니고 탄약만 충전함.

다운로드
https://github.com/3bgdragon/let-it-die-vending-enhancement
들어가서 Code → Download ZIP으로 받으면 됨.

사용법
Node.js 22.5 이상 설치 → 압축 풀기 → 게임 완전히 종료 → run.bat → 1번 적용.
적용 전에 세이브는 별도로 복사해두는 걸 권장함.
제거는 2번인데 게임 파일만 복원하는 거라 이미 구매한 아이템이나 쓴 돈까지 되돌아가진 않음.

백업은 툴 폴더 안이 아니라 바로 옆의 let-it-die-vending-enhancement-backups 폴더에 생김.
업데이트할 때 툴 폴더는 바꿔도 되는데 이 백업 폴더는 지우지 마셈.
예전 내부 백업은 새 버전으로 한 번 실행하면 검증해서 옆 폴더로 복사함. 복사 전에 옛 폴더부터 지우면 안 됨.
alpha.3이나 alpha.4 이미 적용한 사람은 게임 패치가 같아서 재적용 안 해도 됨.
