# 초기 시험판 실게임 확인 순서

## 적용 전

1. 게임을 종료하고 `Savedata` 폴더를 다른 곳에 복사합니다. 확장자 없는 숫자 이름 파일도 포함합니다.
2. 기존 자판기 시험 패치가 있다면 **그 버전 도구와 백업**으로 먼저 복원합니다.
   새 ZIP을 받았다고 이전 `backups` 폴더를 삭제하지 마세요.
3. 이 버전의 `run.bat` → **1번 전체 적용**. Node.js 22.5 이상이 필요합니다.
   미지원 해시 오류가 나오면 강제 적용하지 말고 오류 로그를 전달하세요.
4. 처음에는 저렴한 무기·재료로 시험합니다. 보유 킬코인과 탄약 수를 기록합니다.

## 재료 상점

- 기존 상품·블러드늄 상품이 그대로 있는지 확인합니다.
- 킬코인 재료 상품 구매 시 표시 가격만 차감되고 재료 **5개**가 들어오는지 확인합니다.
- 구매한 묶음은 당일 품절, 다음 기존 일일 갱신 시 재입고/상품 선정을 확인합니다.
  당일 초기화가 이미 끝났으면 패치 직후에는 새 상품이 없을 수 있습니다.
  재고를 보기 위해 세이브나 PC 시간을 임의로 바꾸지 마세요.

## 데칼 교체 / 탈착

- 자판기의 새 항목으로 들어가 취소했을 때 자판기로 복귀하는지 확인합니다.
- 여분의 데칼로 교체/탈착을 시험합니다. 기존 게임의 일반/프리미엄 탈착 규칙은 유지됩니다.
- 자판기를 나왔다가 다시 열고, 저장 후 게임을 재실행해 변경 유지 여부를 확인합니다.

## 탄약 충전

- 일반 상점에서 같은 무기·같은 강화 단계의 구입가를 확인합니다.
  예: 구입가 50,000 → 완충 10,000킬코인. 판매가와 비교하지 마세요.
- 장착한 탄약 무기와 장착하지 않은 데스백 탄약 무기를 각각 시험합니다.
- 목록에는 탄약형 무기만 나오는지, 완충·파손·잔액 부족 무기는 결제 불가능한지 확인합니다.
- 먼저 확인창에서 취소: 돈과 탄약이 바뀌면 안 됩니다.
- 충전 수락: 표시 비용 한 번만 차감, 장전탄/예비탄 완충, 내구도/강화/무기 수 유지.
- 무기를 교체했다 다시 장착하고, 재접속해 탄약과 킬코인이 유지되는지 확인합니다.
- 일반 장비 상점의 기존 판매 기능과 원래 버섯상점 데칼 관리도 확인합니다.

## 오류 시

반복 결제하거나 게임을 계속 진행하지 말고, 상황·스크린샷·`logs/error-*.log`를 남겨 주세요.
게임 실행 중 오류는 도구 로그에 기록되지 않을 수 있으므로 게임 자체 로그도 필요합니다.
게임 종료 → 도구 **2번**으로 파일 복원. 이후 다른 모드가 파일을 변경했다면 복원이 거부됩니다.
**파일 복원만으로 킬코인·아이템·데칼 변경 결과는 되돌아가지 않습니다.** 필요하면 적용 전 보관한 세이브도 별도로 복구해야 합니다.
